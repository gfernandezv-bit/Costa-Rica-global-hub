# Costa Rica Global Hub

## Descripción
Proyecto académico de Diseño Web 1 de la Universidad CENFOTEC.

El sitio presenta información sobre sectores productivos, exportaciones, inversión, innovación y tecnología en Costa Rica.

En este segundo avance se implementó el diseño responsive para adaptar las páginas a diferentes tamaños de pantalla.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Páginas del proyecto
- index.html: Página principal.
- sectores.html: Sectores productivos.
- exportaciones.html: Exportaciones.
- inversion.html: Inversión.
- hubs.html: Centros de innovación.
- landing.html: Costa Rica Tech Hub.

## Diseño responsive
El proyecto utiliza la metodología Mobile First, comenzando con el diseño para dispositivos móviles.

Se utilizan CSS Grid, Flexbox, porcentajes, unidades REM y Media Queries para adaptar el contenido a diferentes pantallas.

El sitio se adapta a celulares, tabletas y computadoras de escritorio.

## Navegación
El sitio cuenta con un menú de navegación que permite desplazarse entre las diferentes páginas.

En dispositivos móviles se utiliza un menú hamburguesa que se abre y se cierra mediante JavaScript.

La página actual permanece resaltada en verde para facilitar la navegación.

## Página Costa Rica Tech Hub
La landing presenta información sobre innovación, talento humano, áreas estratégicas, historias de éxito y sostenibilidad.

Incluye tarjetas con fotografías WebP, iconos SVG, botones de navegación y una sección de preguntas frecuentes interactivas.

## Organización de archivos
- css/: Archivos de estilos.
- js/: Archivos JavaScript.
- img/: Fotografías e imágenes del proyecto.
- svg/: Iconos utilizados en las páginas.
- wireframes/: Diseños de referencia para escritorio y celular.

## Validación
Se realizaron revisiones del funcionamiento del menú, los enlaces, las imágenes y las preguntas frecuentes.

También se revisó el diseño responsive en diferentes tamaños de pantalla y se utilizaron herramientas de validación para HTML y CSS.

## Cómo abrir el proyecto
1. Abrir la carpeta del proyecto.
2. Buscar el archivo index.html.
3. Abrir index.html en un navegador web.
4. Utilizar el menú para navegar entre las páginas.
